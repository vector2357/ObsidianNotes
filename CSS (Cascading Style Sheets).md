### Introdução


*CSS* é a linguagem usada para **estilizar** páginas web. Enquanto o [[HTML (HyperText Markup Language)]] define a **estrutura** do conteúdo, o CSS é responsável pela **aparência visual**, como cores, tamanhos, posicionamento, fontes, espaçamentos e animações.

A principal função do CSS é **separar o conteúdo da apresentação**, promovendo maior organização, flexibilidade e reutilização do código. Ele permite que o desenvolvedor defina um estilo consistente para toda a página ou site, e personalize visualmente cada elemento da interface.
